## Bugs and issues (with repro)

1. Intermittent false "Page not found" / "Something went wrong" on valid pages. Repro: fresh browser context with saved login, open /inspect/itps/769e66b9-8e5d-4c53-ba5d-0ddfd51661a0 (as inspector, scoped, client or contractor): first load says "Page not found", reload shows the ITP. Also the generic error boundary (digests 2447297072, 2759915828) on /inspect/settings, /inspect/projects/new, /platform for non-admin roles on the first or second try before the redirect works. Pages seem to treat a failed query as not-found. Severity: medium (looks like lost access).
2. Project pages sometimes show "No parties recorded on this project yet." / "No project parties configured..." and an empty sign-off grid when the parties query fails, with no error. Repro: admin opens THP-2026-001 project page (observed twice), scoped inspector opened MER ITP (first load). Silent empty state hides a failure.
3. Data Book page and KPIs page fail for all roles late in run: "The Data Book readiness could not be calculated right now. A data query failed". Blocks M2 data-book compile checks and K7 click tests. Possibly caused by concurrent testing load; re-test.
4. TPI (and client, sub, contractor) can open "+ Raise NCR" with Minor/Major severity and edit NCR close-out fields (Save progress). Playbook M4 expects no raise/close/edit. Server enforcement unknown.
5. NCR detail "Assigned to" dropdown (disabled) exposes all users' names to external logins; Reassign picker shows emails (admin only).
6. Sub and contractor see a "Generate Data Book" control on the MER data-book page (inventory taken before the page broke). Needs re-verification.
7. Dashboard overdue-hold count (74) includes holds on closed projects (10 on E2E-001) while the Projects list hides closed projects (64).
8. K7 definitions differ from the playbook (ITP completion, first-time pass rate, NCR severity open/closed split); Inspections-completed card (2/2 100%) contradicts "Inspection completion by ITP" (1/2 50%) on MER-2026-001.
9. Inspector can open /inspect/settings (limited Client Teams/Teams view) and sees "ADMIN > Teams / Client Teams" in the menu; playbook says no Settings and a redirect.
10. Forbidden address for sub (/inspect/projects/c0000000-...-0002) shows the generic error boundary instead of Page not found; Page-not-found responses return HTTP 200.

Playbook-wording mismatches (not bugs): K1 Active ITPs definition, K1 NCR "Open count" vs Open+In progress, K3 Needs-attention formula, K5 "Work awaiting your review" (main contractor only), K2 NCR panel / New inspection button, M1 itp-master redirect target (/inspect/itps), M5 settings redirect, M6 "Your organisations" (admin only).
