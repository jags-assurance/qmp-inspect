# User Guide

Sidebar groups: **Plan** (Projects, ITPs), **Execute** (Start work, Inspections, Standalone Assignments), **Quality** (NCRs, Observations), **Records** (Reports & Documents, Document Vault, Data Book / Handover), **Admin** (Settings, Manage), plus Dashboard, Notifications and Guide. Ctrl+K searches everything.

## JAGS admin
1. Settings: Client Organisations, Staff Access, Numbering, Brand Colors, Automation Rules.
2. Plan > Projects > create a project; add parties and provision their logins (the temporary password shows once).
3. Approve ITPs, close NCRs and punch items, approve vault documents.
4. Records > Data Book: compile (override only with a documented reason; an override, a conditional handover or withdrawing a compiled book needs an Admin) and issue handover. A Data Book is ready only when every activity is inspected and passed and hold/witness points are signed off.

## JAGS inspector
1. Plan > ITPs: build or copy from Master ITP Library; submit for review.
2. Execute > Start work: choose the activity, run the checklist. Use **Document** on an item to attach vault or uploaded files.
3. Complete the inspection; on a pass issue the IRN (a wrong IRN can be voided and replaced). Staff can re-open a completed inspection with a reason.
4. Quality > NCRs for failures; keep punch items moving.

## Client
1. Dashboard shows what needs your action.
2. Review and accept ITPs; sign your own hold/witness/review cells.
3. Raise Observations; check Reports & Documents.
4. Records > Handover: open the Data Book and acknowledge receipt, or reject the package with a reason if it is not acceptable (you will get reminders while a certificate is waiting). A rejected certificate is replaced by a new revision from JAGS.

## Main contractor and subcontractor
1. Execute > Inspections: run checklists for your own work, add photos and per-item documents.
2. Sign only your own party's cells. Respond to hold/witness notices.
3. Resolve NCR corrective actions (sending an NCR for verification needs evidence) and punch items (resolving needs a fix photo; closing needs an Admin or a permission holder). Contractors and TPIs cannot read Data Books or handover packages.
4. Add register entries and certificates if you are a register contributor.

## TPI / lab
Review and witness only: sign your own cells, add test records. You do not run checklists.

## Everyone
- Notifications page shows alerts and the true unread count.
- Exports (Excel/Word, vault ZIP) are limited per user per minute; if you see "Too many requests", wait a few seconds and try again.
- Offline work: answers and photos queue on the device and sync when you are back online; a queued item is only replayed under the user who recorded it.
- Project > Guide explains who is on that project and what you are responsible for.
